# Python Refresh

**Goal:** Refresh modern Python and strengthen object-oriented design judgment.

**Scope:** Decorators, context managers, dataclasses, ABCs and protocols, generators, type hints, mypy, pytest, property-based testing.

**Out of scope:** Django/DRF (see `drf-basics`).

**Learning focus:** Choosing composition vs. inheritance, designing small interfaces, avoiding surprising decorator behavior, using types and tests to make contracts explicit.

**Depends on:** None.

## Milestones
- [ ] Implement and test a typed decorator and context manager.
- [ ] Model a small domain with dataclasses and a `Protocol`; compare with an ABC.
- [ ] Add strict type checking and parametrized pytest tests.
- [ ] Add a Hypothesis property test and explain the invariant it checks.
