# System Design Domain Knowledge

This repository is a mechanism-first learning path for system design. Use the [curriculum index](system-design/README.md) to study concurrency, database correctness, distributed systems, geospatial search, search engines, media delivery, and probabilistic data structures.

Each topic explains **why** the problem matters, **how** a solution works, and **what happens under the hood**, then applies that understanding to production constraints, failure modes, trade-offs, and exercises. The sequence targets senior engineers: reason from invariants, workload, and SLOs rather than pattern names alone.

Start here: [System Design Fundamentals](system-design/README.md).
