# Sudoku Solver

**Goal:** Practice algorithmic problem solving through a correct, measurable Sudoku solver.

**Scope:** Validation, backtracking, constraint propagation, variable-ordering heuristics, optional graph-coloring formulation.

**Out of scope:** Web UI and puzzle generation.

**Learning focus:** State representation, invariants, search pruning, algorithmic complexity, property-based tests.

**Depends on:** `python-refresh` testing and typing practices.

## Milestones
- [ ] Define the board representation and validity invariants.
- [ ] Implement a simple backtracking solver with known-puzzle tests.
- [ ] Add constraint propagation and measure its effect.
- [ ] Add property-based tests and compare heuristic choices.
