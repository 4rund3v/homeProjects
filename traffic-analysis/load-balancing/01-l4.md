# 01 — L4 load balancing (MetalLB in this project)

## What L4 means, precisely

L4 = TCP/UDP. The L4 LB (MetalLB here) is not an application server. It is a *kernel-level* router that accepts TCP connections on a VIP and forwards them to a backend pod IP:port. It sees:

- Source/dest IP, port.
- TCP flags (SYN, ACK, FIN, RST).
- Nothing else. Not the HTTP method, not the path, not the body.

## How MetalLB works (short version)

MetalLB advertises a VIP to the local network. For `layer2` mode, it answers ARP for the VIP on one node at a time. For `bgp` mode, it peering-exchanges routes.

When a client TCP-connects to the VIP:

1. The kernel on the MetalLB-managed node accepts the SYN.
2. It picks a backend pod IP from the `Service`'s `endpoints`.
3. It DNATs the connection to that pod.
4. The pod's traffic is handled by `kube-proxy` iptables/IPVS rules, which then round-robins across *replicas* of the pod.

So the actual path is: VIP → node → (kube-proxy) → pod. The VIP is one layer of LB; kube-proxy is a second layer. Both are L4.

## What to observe

- `MetalLB` logs — which node is advertising the VIP.
- `kube_pod_info` vs actual connections — L4 has no per-request view; you see per-pod TCP connection counts via node-exporter, not per-request.
- `iptables` / `ipvsadm` on the node — the actual DNAT rules.

## The L4 failure mode you will measure

Kill one app pod. The VIP keeps sending to the dead pod's IP until:

- `kube-proxy` refreshes iptables (~30 s default), or
- the L4 health check (if the cloud LB has one) marks the endpoint down (~10–30 s).

During that window, 100% of new connections to the dead pod's IP time out. The p99 (not the p50) carries that pain. This is the `load-balancing/labs/kill-a-pod.md` lab.

## L4 health checks

The cloud LB (or MetalLB with `BGP` mode) runs a *TCP* health check: connect to pod IP:port, expect a successful TCP handshake. No HTTP. No application check. So a pod that is up but returning 500s passes the L4 health check.

That is why L7 health checks exist (next doc). L4 and L7 health checks answer *different questions*.
