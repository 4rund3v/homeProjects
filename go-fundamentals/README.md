# Go Fundamentals

**Goal:** Build fluency in idiomatic Go before taking on networked services.

**Scope:** Types, structs, methods, interfaces, embedding, errors, `context`, goroutines, channels, synchronization, standard library, modules, tests, benchmarks.

**Out of scope:** HTTP, databases, external infrastructure.

**Learning focus:** Composition and interfaces, explicit error handling, ownership/concurrency reasoning, table-driven tests, race detection.

**Depends on:** None.

## Milestones
- [ ] Create a Go module and small typed package.
- [ ] Implement a concurrent worker pipeline with cancellation.
- [ ] Add table-driven tests, benchmarks, and run `go test -race`.
- [ ] Explain the package boundaries and concurrency invariants before moving on.
