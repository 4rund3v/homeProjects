# Django REST Framework Basics

**Goal:** Refresh Python through a small tested API backed by PostgreSQL.

**Scope:** Django models/migrations, DRF serializers and viewsets, authentication, OpenAPI schema, pytest and API tests.

**Out of scope:** Large frontend, production identity federation (see `keycloak-setup`).

**Learning focus:** ORM vs. SQL, request/serializer boundaries, migrations, API contracts, test database behavior.

**Depends on:** `python-refresh`.

## Milestones
- [ ] Build a small resource API with validation and CRUD tests.
- [ ] Add PostgreSQL and exercise migrations against it.
- [ ] Add authentication and test authorization failures.
- [ ] Generate an OpenAPI schema and check it against observed behavior.
